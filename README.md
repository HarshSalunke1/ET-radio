# ⚽ Extra Time Radio

> **FOOTBALL · MUSIC · EXTRA TIME**  
> An atmospheric, late-night football radio experience combining high-definition 4K photography, glassmorphism UI design, and continuous curated soundscapes.

---

## 🌟 Key Features

- **Translucent Glassmorphism UI**: Floating pill capsule music player bar with backdrop blur filters (`blur(24px)`), smooth progress tracking, and ambient equalizer canvas.
- **Continuous Shuffled Autoplay**: Integrated audio engine using YouTube Music Playlist stream API with instant browser-compliant autoplay and zero track repetition.
- **4K UHD Football Wallpaper**: Full-screen cinematic football photography featuring iconic football moments.
- **Live Environmental Context**: Understated top navigation bar with a live digital clock, online listener indicator badge, and external streaming links (Spotify, YouTube Music).
- **Keyboard Controls**: Full keyboard accessibility (`Space` for play/pause, `Left/Right Arrows` for prev/next tracks, `M` key for mute).

---

## 🛠️ Tech Stack

- **Framework / Build Tool**: [Vite](https://vitejs.dev/)
- **Audio Engine**: Web Audio API & YouTube IFrame API Integration
- **Typography**: Syne, Manrope, Inter (Google Fonts)
- **Icons**: FontAwesome 6
- **Styling**: Vanilla CSS Custom Properties & Glassmorphic Surfaces

## 🚀 Quickstart Guide

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v16+) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HarshSalunke1/ET-radio.git
   cd ET-radio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
